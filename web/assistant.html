接入与文件格式

在平台目录复制 assistant.local.example.json 为 assistant.local.json，填写兼容 Chat Completions 的 API 地址、模型和密钥。密钥仅在服务端读取，不随页面返回。

CSV / XLSX首行 / JSON任务字段：

id,name,kind,start,end,earliest,deadline,service,demand,water,priority

时间单位：当日分钟；水量、载重沿用现有场景单位。节点必须已存在。完整字段校验通过才导入。XLSX读取第一个工作表；PDF仅提取文字，扫描PDF请提供图片。地图图片不能直接推断坐标；需提供节点对应关系。图片识别要求模型支持视觉。
